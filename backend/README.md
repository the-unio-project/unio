# Backend

Backend for the Unio project.

## ⚙️ Dependencies (Contribution)

- **Python 3.14.7**

For the other dependencies, to avoid autocomplete/error detection errors you should use python **venv** which separates ur global pip installs from those of the project.

- **fastapi[standard]==0.141.1**
- **SQLAlchemy==2.0.52**

### ( 1 ) - VENV Initialization
```bash
# creates the virtual environment
python -m venv .venv
```
### ( 2 ) - Windows *(powershell)*
```bash
.\.venv\Scripts\Activate

pip install
```
### ( 2 ) - Linux/MacOS *(zsh/bash)*
```bash
source .venv/bin/activate
```

### ( 3 ) - Install Dependencies
```bash
pip install fastapi[standard]==0.141.1 SQLAlchemy==2.0.52
```
